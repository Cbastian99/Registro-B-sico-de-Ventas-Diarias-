# Registro-B-sico-de-Ventas-Diarias-
Desarrollar un programa en Python que permita registrar una venta individual, aplicar reglas básicas del negocio (cálculo de subtotal y descuento VIP del 10%) y mostrar un resumen claro en consola.  El sistema procesará una sola venta por ejecución y no incluirá persistencia de datos ni interfaces gráficas.
